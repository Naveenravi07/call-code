# 🚀 Installation Guide

Setup Docker, Kubernetes, Istio Gateway, and DNS for local development.

---

## ✅ Prerequisites

Install:

- `docker`
- `minikube`
- `kubectl`
- `istioctl`
- `dnsmasq`

---

## ⚙️ Setup

### 1. Install Istio Ingress Gateway Only

**Option 1: Minimal profile**
```bash
istioctl install --set profile=minimal
```

**Option 2: Empty profile with only ingress gateway**
```bash
istioctl install --set profile=empty \
  --set "components.ingressGateways[0].enabled=true" \
  --set "components.ingressGateways[0].name=istio-ingressgateway" \
  --set "components.pilot.enabled=true" \
  --set "values.global.istioNamespace=istio-system" -y
```

Then:

```bash
git clone https://github.com/your-org/call-code-base-images
cd call-code-base-images/k8_examples
kubectl apply -f gateway.yaml
```

Check services:
```bash
kubectl get svc -n istio-system
```

Expected output:
```
NAME                   TYPE           CLUSTER-IP       EXTERNAL-IP    PORT(S)
istio-ingressgateway   LoadBalancer   10.111.121.8     10.111.121.8   80:32737/TCP,...
istiod                 ClusterIP      10.109.214.109   <none>         443/TCP,...
```

---

### 2. Start Minikube

```bash
minikube start
minikube tunnel
```

---

### 3. Get Gateway IP

```bash
kubectl get svc istio-ingressgateway -n istio-system
```

Copy the `EXTERNAL-IP`.

---

### 4. Configure DNS with dnsmasq

Edit `/etc/dnsmasq.conf`:

```
address=/call-code.local/[your-gateway-ip]
server=1.1.1.1
```

Restart dnsmasq:
```bash
sudo systemctl restart dnsmasq
```

---

## 🛠 DNS Troubleshooting

### On Host

**/etc/dnsmasq.conf**
```
address=/call-code.local/[your-gateway-ip]
server=1.1.1.1
```

**/etc/resolv.conf**
```
nameserver 127.0.0.1
options edns0 trust-ad
```
